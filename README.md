# Machine Learning Experiments

A collection of Machine Learning experiments covering data preprocessing, visualization, dimensionality reduction, regression, and classification using Python and Scikit-learn.

## Experiments

### 01. Data Pre-processing

* Missing value handling and data cleaning
* Normalization and standardization
* Preparing datasets for machine learning models

### 02. EDA & Visualization

* Descriptive statistics and data exploration
* Distribution and relationship analysis
* Data visualization using Matplotlib and Seaborn

### 03. Regression Algorithms

* Linear Regression
* Logistic Regression
* Model training, prediction, and evaluation

### 04. Principal Component Analysis (PCA)

* Feature standardization and dimensionality reduction
* Explained variance analysis
* 2D visualization of transformed data

### 05. Support Vector Machine (SVM)

* Linear and non-linear classification
* Support vectors and margin concepts
* Kernel methods with RBF and feature scaling

### 06. K-Nearest Neighbors (KNN)

* Distance-based classification
* Euclidean distance and feature scaling
* Model prediction and performance evaluation

### 07. Regression Algorithms Comparison

* Linear and Polynomial Regression
* Decision Tree and Random Forest Regression
* Support Vector Regression (SVR)
* Evaluation using MAE, MSE, and R²

### 08. Classification Algorithms Comparison

* Logistic Regression
* Decision Tree and Random Forest
* SVM and KNN
* Naïve Bayes
* Evaluation using Accuracy, Precision, and Recall
